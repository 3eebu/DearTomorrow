**Storage and boundaries.** Each of Books, Tree, Letters and Journeys has its own IndexedDB implementation. React state holds unfinished interactions. Signed-in personal mode routes through the cloud scope, server-side document validation, Supabase Postgres and private media storage. Session cookies are HTTP-only with HTTPS-dependent Secure. Server actions cover identity and connection management. The private-space handler also handles temporary chunked cloud transfers. The repository includes four migration files, confirmation and recovery templates and the local Supabase configuration.

**Operating dependencies.** Next.js, React, Supabase Auth/PostgREST/Storage, conditional Google and Apple OAuth, Vercel and domain configuration, email provider/SMTP, scheduled temporary-fragment cleanup and any external font/media resources discovered at runtime. No payment or subscription application flow was found. Paid checkout is frozen scope. Happy-path guest interaction cannot establish cloud, scheduled recipient or delivery status.

**Flags and examples.** The public workspaces and personal `space=mine` are distinct. Provider availability depends on the provider setting as well as application flags. Memory Book frame profiling uses `profile=1`; the environment inspector requires development mode and `studio=environment`. Embedded examples and synthetic recordings must be distinguished from saved user content. The cinematic experimental tree is a separate development route.
