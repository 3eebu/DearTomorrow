# Design system

## Visual thesis

A contemporary heirloom: quiet luxury stationery, archival books, intimate film-like still life, and small botanical details with generous editorial space. Original compositions use warm light and tactile materials without retro clutter or borrowed visual identity.

## Type and layout

- Titles: Georgia / Iowan Old Style system serif; italic serif for a few emotional phrases.
- Interface and body: system sans stack for legibility and fast local rendering.
- Maximum reading width: about 68 characters; wide editorial grid rather than generic dashboard cards.
- Mobile compositions reflow into one column and a single-page book reader.
- Focus indicators, semantic headings, visible labels, 44px touch targets, and sufficient color contrast are required.

## Material treatment

Paper uses local grain, layered light, and restrained shadows. The hero letter and open book use original, optimized artwork in `public/media/`; interactive text and controls stay in the DOM. The more detailed future studio needs licensed/owned photo frames, cover textures, stickers, stamps, paper, tape, foil, pressed flowers, and uploaded partner media.
