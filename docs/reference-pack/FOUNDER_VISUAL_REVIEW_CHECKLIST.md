# DEAR TOMORROW — FOUNDER'S FIRST VISUAL QUALITY CHECKLIST

Use this after Codex completes the first interactive website prototype. If any core item fails, return the item to Codex for revisions BEFORE proceeding to account/database work.

## 1. First impression
- [ ] Would an ordinary visitor recognize the brand as an intimate, premium interactive experience in 5 seconds?
- [ ] Is the palette classy and consistent (ivory, parchment, burgundy), with beautiful readable typography and charming details?
- [ ] Does the first envelope truly unfold with believable layers, occlusion and shadow—not just fade a flat rectangle in?
- [ ] Are textures / photographic layers genuinely rich, not low-quality placeholder vectors or watermarked stock?
- [ ] Is the homepage storytelling original rather than copying any competitor?

## 2. Create and navigation
- [ ] Prominent “Create” opens a beautiful sheet/menu with Letters, Journey Letters, Memory Book and Our Dates.
- [ ] Every enabled visible action genuinely responds.
- [ ] The user can explore core examples without registering.
- [ ] Moving around the site never causes disorienting forced intro animations.

## 3. Memory Book
- [ ] Can I change the book's name to anything and immediately see the cover update?
- [ ] Can I choose a cover color/theme?
- [ ] Does opening the book feel like handling an actual hardcover with spine, paper, depth and lighting?
- [ ] Can I turn pages on desktop with arrows and gestures?
- [ ] Can I turn readable **single** pages on mobile via touch?
- [ ] Does each page have beautiful photoframe/paper/decorative depth, not plain boxes?
- [ ] Is the scope of sample/demo editing honestly distinguished from real persistent editing?

## 4. Our Dates
- [ ] Are there beautiful organic connecting lines and smaller branches, not just an unanimated vertical list?
- [ ] Do lines visibly grow as they become relevant?
- [ ] Can I expand a milestone, add a fictional sample moment and switch to Calendar?
- [ ] Does Calendar show the same moments as Timeline?
- [ ] Is the mobile timeline visually pleasant, readable and usable without hover or horizontal scrolling?

## 5. Journey teaser and letters
- [ ] Do the fictional six checkpoints appear with clear times and a route motif?
- [ ] Are future/locked letters distinguished from available letters?
- [ ] Does the user understand website unlocks require a connection, whereas robust offline is a future native-app capability?

## 6. Responsiveness, accessibility and quality
- [ ] Inspect 390px phone and 1440px desktop screenshots and actually interact with both.
- [ ] No clipping, unreadable fonts, horizontal overflow, overly slow scrolling or taps that do nothing.
- [ ] Keyboard can reach interactive controls; reduced-motion users can read/use the page.
- [ ] Site can start, build, typecheck and run tests as reported; any unrun checks are marked honestly.
- [ ] Codebase remains organized and ready for real accounts, book saving and scheduled letters later.
